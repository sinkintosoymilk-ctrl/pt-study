# プロジェクト現状（v129）

## 基準

`pt-study` 既存リポジトリから取得したアプリZIPを起点とし、最後の機能追加版はv128です。今回のv129は、**公開できる形に整え、現状を誰でも確認できるようにするための整理版**です。新規アプリではありません。

## 検証済みの範囲

- 問題数2,000、採点対象1,975、公式採点除外25、重複IDなし
- 画像286点、`data/figure-manifest.json` にある全ファイルが存在すること
- 原図復旧対象22問がアプリ表示に対応していること（v127の確認を継承）
- 5肢別解説登録262問、知識分析123問、関連リンク167件
- 少数の代表的問題の解答・解説表示、年度別導線、図表示、採点除外の挙動（公開前にも要確認）

## 未検証・未完了

- 全2,000問の一次資料への逐字独立照合
- 画像がある全問題の原本との画像内容・ラベル・向きの全面監査
- 選択肢別解説の全面的な医学的正確性監修
- 知識接続を2,000問すべてへ展開、各リンクの適合性の専門的検証
- 利用者の実機端末（iOS/Android各端末）やCloudflare公開URLでの動作試験

## 制約・事故防止

- `data/questions.js`、正答キー、問題IDはv128から変更しない。
- 既存の画像は削除せず、当該22問の問題IDと公式図の対応を保持する。
- 個人の学習履歴JSONをGitHubへ置かない。
- ブラウザの`localStorage`を初期化しない。
- 重要な未監修事項は「完全監修済み」と表示しない。
